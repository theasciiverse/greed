= Welcome to greed

The object of Greed is to much as munch of the screen as possible by
moving around in a grid of numbers - use your awrrow keys. Beware! the
length of your next move is forced by the number you land on.

Run this in an ANSI-compatible terminal emulator. Only requires cursor
motion, the base 8 colors, and a small subset of the screen-elacing
controls. Any xterm descendant or workalike is more than sufficient.

Needs the Rust compiler to build the code, amd asciidoctor to render
the documentation.

This code is commonly packaged as "greed".
