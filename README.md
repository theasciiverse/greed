# Greed

Munch as much of a grid of numbers as you can; each number decides how far you move.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install greed
av play greed
```

Or download the archive for your system from this repository's Releases,
unpack it and run `./greed` (`greed.exe` on Windows).

## Credits

Matt Day wrote Greed in C (to 3.0a, 1990); Eric S. Raymond has maintained it
since and ported it to Rust in 5.0 (2026). Asciiverse builds ESR's Rust
version unchanged.
